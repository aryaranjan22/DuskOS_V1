# duskOS 🌙

duskOS is a lightweight operating system simulator that runs entirely in your web browser.

It is **not a real operating system**. Instead, it is a small desktop environment built with **HTML, CSS, and JavaScript**, designed to feel a little like a modern desktop OS with a glassy, minimal interface.

##  What is duskOS?

This started as my first attempt at building something that feels like an operating system.

I wanted to make a desktop that had things like:

- A menu bar
- A dock/taskbar
- Desktop icons
- Glass-style windows
- Window animations
- Minimize, maximize, and close controls
- A Dynamic Island-style search panel
- A control center
- A few built-in apps

The whole project was made from scratch and is meant to be simple, lightweight, and fun to experiment with.

## 🖥️ Current Features

duskOS currently includes:

-  **Finder** — a simple file browser interface
-  **Notes** — a small notes app with multiple notes
-  **Terminal** — a basic fake terminal with commands
-  **Calculator** — a working calculator
-  **Vibes** — a small music player interface
-  **Weather** — a sample weather app
-  **Settings** — appearance, wallpaper, and sound settings
-  **About** — basic system information

The desktop also has draggable and resizable windows, minimize/maximize/close controls, a dock with magnification, a control center, and a Dynamic Island-style Spotlight search.

##  Design

I wanted duskOS to have a calm, slightly futuristic look, so I went with:

- Glass UI (IOS like)
- Soft shadows
- Rounded windows
- Smooth animations
- A dark purple/pink color palette
- A custom wallpaper
- A minimalistic interface inspired by modern operating systems ie MacOS

The goal wasn't to copy an existing OS exactly, but to make something that **feels familiar while still having its own style**.

##  Built With

duskOS is made using:

- **HTML**
- **CSS**
- **JavaScript**

No frameworks or complicated setup are required.

Just open the project in a browser and it should run.
